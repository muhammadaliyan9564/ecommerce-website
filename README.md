# E-Commerce Web Application

A full-stack e-commerce platform built for product browsing, dynamic shopping cart management, user accounts, and order workflows[cite: 1].

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5[cite: 1]
- **Backend:** PHP[cite: 1]
- **Database:** MySQL[cite: 1]

## ✨ Key Features
- 🛍️ **Product Catalog:** Responsive layout to showcase products with images, details, and live pricing[cite: 1].
- 🛒 **Shopping Cart:** Add items to cart, adjust quantities, remove items, and auto-calculate subtotal[cite: 1].
- 👤 **User Accounts:** Registration and login system for customer account management[cite: 1].
- 📦 **Order Management:** Checkout functionality to record customer orders into the database[cite: 1].
- ➕ **Product Management:** Admin panel / form to add new products to the catalog[cite: 1].
